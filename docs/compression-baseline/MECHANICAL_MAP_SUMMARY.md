## Mechanically important observations

These are graph/reachability facts only, not mathematical judgments.

1. `rankThreeKUM` has five direct project-local dependencies: `UniformlyDense`, `CyclicBasisOrder3`,
   `rankThreeKUM_of_small_two_and_strict_deletion`, one generated proof declaration associated with
   that theorem, and the active structural six-point endpoint.
2. The active theorem closure contains 647 of the 901 loaded project declarations; 254 are outside it.
3. The largest loaded-but-inactive concentration is `Rank3KUM.Version2.HalfWeave` with 85 declarations.
   The version-2 near-tight and residual-support alternative modules are also outside the active root
   closure. This matches the repository's v2 alignment manifest, which explicitly says these revised
   routes are compiled alternatives rather than dependencies of `rankThreeKUM`.
4. The structural version-2 six-point modules are active. The old `SixPointCombinatorics` module is
   wholly outside the root closure, while `SixPointMatroid` remains partly active because the new
   structural bridge still uses shared six-point matroid geometry.
5. The current tight-set endpoint `exists_cyclicBasisOrder3_of_nonempty_proper_tight` has a 239
   declaration project-local closure. Its rank-one and rank-two endpoints have closures of 213 and
   215 declarations respectively.
6. `TwoGap.universalTwoGapInsertion` has a 133-declaration project-local closure. The higher-level
   deletion-to-cyclic-order endpoint `exists_cyclicBasisOrder3_of_cyclic_basis_deletion` has a
   218-declaration closure.
7. The current strict-case hitting-basis endpoint
   `exists_isBase_hitsNearTight_of_strict_rankThree` has a 46-declaration closure, concentrated in
   `NearTightGeometry` and `StrictDensity`.
8. The active six-point endpoint has a 365-declaration closure because it also handles the tight-set
   alternatives before invoking the structural strict six-point argument.
